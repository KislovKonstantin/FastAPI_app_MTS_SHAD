# Book Shop

Приложение на FastAPI с использованием PostgreSQL и JWT-аутентификации в рамках финального проекта по Python ШАД МТС

## Стек технологий

- Python 3.10+
- FastAPI
- SQLAlchemy 2.0
- PostgreSQL
- Pydantic v2
- JWT
- Passlib
- Pytest

## Установка и настройка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/KislovKonstantin/FastAPI_app_MTS_SHAD
   ```

2. **Создайте и активируйте виртуальное окружение**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости**
   ```bash
   pip install -r requirements.txt
   ```

4. **Укажите актуальные параметры подключения к PostgreSQL в .env**

5. **Подключитесь к PostgreSQL и выполните запросы из postgres/create_databases.sql**

## Запуск приложения

```bash
uvicorn src.main:app --reload
```

Приложение будет доступно по адресу `http://127.0.0.1:8000`  
Документация Swagger: `http://127.0.0.1:8000/docs`

## Документация API

### Книги (Books)

| Метод | Эндпоинт | Описание | Доступ | Тело запроса | Ответ |
|-------|----------|----------|--------|--------------|-------|
| POST | `/api/v1/books/` | Создание новой книги | После авторизации | `{"title": "...", "author": "...", "count_pages": 300, "year": 2026, "seller_id": 1}` | `201` со списком книг |
| GET | `/api/v1/books/` | Список всех книг | Открытый | - | `200` `{"books": [...]}` |
| GET | `/api/v1/books/{book_id}` | Получение одной книги | Открытый | - | `200` с объектом книги |
| PUT | `/api/v1/books/{book_id}` | Полное обновление книги | После авторизации | `{"title": "...", "author": "...", "count_pages": 300, "year": 2026, "id": 1, "seller_id": 1}` | `200` с обновлённым объектом |
| PATCH | `/api/v1/books/{book_id}` | Частичное обновление книги | Открытый | `{"count_pages": 350}` (любые поля) | `200` с обновлённым объектом |
| DELETE | `/api/v1/books/{book_id}` | Удаление книги | Открытый | - | `204 No Content` |

### Продавцы (Sellers)

| Метод | Эндпоинт | Описание | Доступ | Тело запроса | Ответ |
|-------|----------|----------|--------|--------------|-------|
| POST | `/api/v1/seller/` | Регистрация нового продавца | Открытый | `{"first_name": "...", "last_name": "...", "e_mail": "...", "password": "..."}` | `201` с объектом продавца |
| GET | `/api/v1/seller/` | Список всех продавцов | Открытый | - | `200` `{"sellers": [...]}` |
| GET | `/api/v1/seller/{seller_id}` | Данные продавца с его книгами | После авторизации | - | `200` `{"id": ..., "first_name": ..., "last_name": ..., "email": ..., "books": [...]}` |
| PUT | `/api/v1/seller/{seller_id}` | Обновление данных продавца | Открытый | `{"first_name": "...", "last_name": "...", "e_mail": "..."}` | `200` с обновлённым объектом |
| DELETE | `/api/v1/seller/{seller_id}` | Удаление продавца и всех его книг | Открытый | - | `204 No Content` |

### Аутентификация

| Метод | Эндпоинт | Описание | Тело запроса | Ответ |
|-------|----------|----------|--------------|-------|
| POST | `/api/v1/token/` | Получение JWT-токена | `application/x-www-form-urlencoded` с полями `username` (email) и `password` | `200` `{"access_token": "...", "token_type": "bearer"}` |

### Примечания по элиасам

- В запросах на создание и обновление книг поле `count_pages` отвечает за количество страниц, в ответах оно возвращается как `pages`.
- В запросах на регистрацию и обновление данных продавцов поле `e_mail` отвечает за почту (`username`), в ответах оно возвращается как `email`.

## Аутентификация и авторизация

Для доступа к защищённым эндпоинтам необходимо включить в заголовок `Authorization` токен, полученный через `/api/v1/token/`, в формате:
```
Authorization: Bearer <токен>
```

### Правила доступа

- **Только аутентифицированные продавцы** могут:
  - Просматривать только свои данные, иначе вернётся ошибка `403 Forbidden`.
  - Создавать только свои книги, вернётся ошибка `403 Forbidden`.
  - Обновлять только свои книги, вернётся ошибка `403 Forbidden`.
- **Незащищённые эндпоинты** (регистрация, списки, получение одной книги, частичное обновление, удаление книг, обновление продавца, удаление продавца) доступны без токена.

### Пример получения токена

`POST`, `x-www-form-urlencoded`:
- `username`: email продавца
- `password`: его пароль

Ответ:
```json
{
    "access_token": "...",
    "token_type": "bearer"
}
```

## Тестирование

Приложение покрыто тестами pytest. Для запуска тестов выполните:

```bash
pytest -v
```

## Особенности реализации

- При удалении продавца все его книги удаляются каскадно.
- Год книги не может быть меньше 1500.
- Пароль никогда не возвращается в ответах.
